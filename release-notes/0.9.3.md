ClipShot no longer misses a screenshot that macOS saves late.

- When Spotlight is busy, macOS can hold a new screenshot back for a minute or more before it shows up in the folder. ClipShot used to skip such a screenshot as too old, so nothing reached the clipboard. Now it is copied as soon as it appears.
- A screenshot put back from the Trash or moved into the folder is still never copied, as before.
- A second copy of ClipShot, for example one opened from a disk image while the installed one runs, now quits on its own instead of adding a second menu bar icon that copies every screenshot twice.

Signed with Developer ID, notarized and stapled. Requires macOS 26.

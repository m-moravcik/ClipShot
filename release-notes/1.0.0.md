The first release. Take a screenshot and paste it: ClipShot puts every screenshot on the clipboard the moment macOS saves it, and the file stays where macOS saves it.

- Its own floating preview, so the copy does not wait for the macOS thumbnail. Click it to mark the screenshot up in Markup and the edited image is copied, drag it into any app, or swipe it away. Prefer the macOS thumbnail? Pick it in Settings; copying then waits until the thumbnail goes away.
- The menu bar popover shows the latest screenshot and the four before it, with Copy, Show in Finder and Move to Trash. A screenshot moved to the Trash can be put back with Undo for a few seconds.
- Optional cleanup, off until you turn it on: screenshots older than a period you choose go to the Trash. Only screenshots ClipShot saw being taken, in the folder you confirmed. Older ones only when you add them yourself, and a renamed screenshot is kept.
- Settings for the macOS screenshot folder and preview, a warning with a one-click fix when macOS is set to send screenshots to the clipboard or an app instead of a file, and Restore previous settings.
- English, Slovak, Czech, German, Spanish and French. A downloaded copy updates itself; a copy installed with Homebrew updates with `brew upgrade --cask clipshot`.

Signed with Developer ID, notarized and stapled. Requires macOS 26.

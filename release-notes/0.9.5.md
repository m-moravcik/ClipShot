Closing Markup without a change no longer touches your screenshot or clipboard.

- On macOS 27, clicking Done in Markup without drawing anything still hands the image back. ClipShot 0.9.4 saved that copy over the screenshot, which made the file about twice as large, and put it on the clipboard again, replacing whatever you had copied since.
- Now ClipShot compares the image with the screenshot. When nothing changed, the file and the clipboard stay as they were. Real edits are saved and copied as before.
- Markup edits of JPEG, HEIC and TIFF screenshots are no longer lost. Markup hands those back in the screenshot's own format, and ClipShot only took PNG, so if you set screenshots to JPEG, Done did nothing.

The `clipshot` command is now one click away for a downloaded copy.

- Settings > General shows whether `clipshot` is installed and where. When it is not, **Install…** links it into `/usr/local/bin` after the standard macOS password prompt, so `clipshot latest` works in Terminal. **Copy Command** copies the same link as a Terminal line, for anyone who prefers to make it by hand.
- A `clipshot` link left pointing to a ClipShot that was moved or deleted is reported, with **Fix…**. Anything else named `clipshot` is left as it is. A copy installed with Homebrew already has the command and is not offered the button.

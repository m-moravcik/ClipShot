Markup edits now stick.

- After you annotate a screenshot in Markup and click Done, the edited image is on the clipboard. On macOS 27 the edit used to be lost: the clipboard kept nothing new, Copy in ClipShot gave the original, and editing again showed the clean screenshot.
- Done now saves the edit over the screenshot, as Markup in Quick Look and Preview do, so a later Copy or a second edit shows your annotations. The file keeps its name, format and creation date, and stays a screenshot ClipShot tracks.

Signed with Developer ID, notarized and stapled. Requires macOS 26.
